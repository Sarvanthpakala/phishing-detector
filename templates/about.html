About the project

Engineering a defensible ML pipeline for URL risk.

SENTRA was built as a complete, end-to-end academic project: dataset construction, feature engineering, model comparison, and a production-style Flask + REST API delivery layer.

The problem

Phishing remains one of the most common initial-access vectors in cyberattacks. Static blocklists lag behind newly registered malicious domains by hours or days. A lexical, ML-based classifier can flag a never-before-seen URL the instant it's submitted, using only the structure of the string itself — no external reputation lookup required.

The dataset

Training data is generated by generate_dataset.py, which encodes the lexical patterns documented in published phishing-URL research (PhishTank / UCI Phishing Websites feature set): typosquatting, IP-hosted links, excessive subdomains, credential-harvesting keywords, and shortener abuse. Every generated URL is passed through the same feature extractor used at prediction time. Drop a real labelled CSV into dataset/ to retrain on live data instead.

Pipeline

What happens between "paste URL" and "verdict."

1. Cleaning

Duplicate rows are dropped, missing feature values are median-imputed, and labels are normalized before any split.

2. Scaling & split

An 80/20 stratified split preserves class balance; StandardScaler normalizes every feature for distance- and gradient-based models.

3. Model selection

Eight classifiers are trained and scored on accuracy, precision, recall, F1 and ROC-AUC. The highest-F1 model is persisted with Joblib.
